# Glossary

## Terms
| Term                 | Meaning                                               | Kind   | Source | Citation |
| -------------------- | ----------------------------------------------------- | ------ | ------ | -------- |
| Muggle               | A person with no magical ability                      | term   | books  | PS ch.1  |
| Triwizard Tournament | A contest between three schools of magic              | event  | books  | GoF ch.12 |
| Time-Turner          | A device that sends its user back a number of hours   | object | books  | PoA ch.21 |
| Horcrux              | An object that holds a piece of a dark wizard's torn soul | object | books | HBP ch.23 |
| Deathly Hallows      | The three objects of the tale of the three brothers, said to make their owner master of Death | object | books | DH ch.21 |
| Elder Wand           | The Hallow that is a wand no duel can beat            | object | books  | DH ch.21 |
| Resurrection Stone   | The Hallow that is a stone to call back the dead      | object | books  | DH ch.21 |
| Invisibility Cloak   | Harry's cloak, the Hallow that hides its wearer, even from Death | object | books | PS ch.12; DH ch.21 |
