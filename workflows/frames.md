# Workflow: frames

Applies when `setting.temporal_model: frames`: time travel, with the travelers' own
timelines and the world-lines they create (§13.5, §9.1).

## Steps

| Step | Agent        | Reads                                                                                                                              | Writes             | Gate | Repeat | Position |
| ---- | ------------ | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------ | ---- | ------ | -------- |
| T1   | canon-keeper | `manuscript/chapter-<NN>.md`; `bible/timelines.md`; `bible/branches.md`; the `bible/time-travel.md` entries the chapter's legs use | `reviews/canon.md` |      |        | after 13 |

## Notes

- **T1** runs only in a project that is not established-world. In an established world,
  E3 makes the frame, mechanism, and paradox checks.
- In a self-contained project, the worldbuilder writes `time-travel.md` at step 3.
- Step 12 (chronicler) also writes `timelines.md` and `branches.md`.
- The drafter marks every scene's world point and travelers.
- An accepted paradox is recorded by a chronicler step on `branches.md`, which the
  showrunner schedules.
